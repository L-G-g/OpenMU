# awesome-design-md (VoltAgent)

Reference catalog, not a workflow. Each folder in `design-md/<site>/` holds a `DESIGN.md`
with that site's tokens: colors, type, spacing, components, motion.

How to use it:
1. Pick 1-3 sites whose mood fits the brief (for a game site: `playstation`, `nintendo-2001`,
   `linear.app`, `raycast`, `warp`, `spotify`...). `ls design-md/` lists them all.
2. Read their `DESIGN.md` and borrow the system (palette roles, type scale, radii, density),
   never the brand itself (logos, names, exact copy).
3. Write the chosen system as the project's own `DESIGN.md` so `impeccable` and
   `design-taste-frontend` work from it.
